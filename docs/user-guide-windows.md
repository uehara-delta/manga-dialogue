# manga-dialogue 利用手順（Windows 版）

Kindle で購入した漫画の画面を自動で撮影し、AI が「誰がどのセリフを言ったか」を書き起こして
Excel などで使える表にするツールです。この手順書は、プログラミングの経験がない方向けに
準備から出力までを順に説明します。

> **ご利用にあたって**
> - 自分で購入した本を、自分のために使う目的に限ってください。書き起こした内容を公開・配布しないでください
> - 本のコピー防止（DRM）を解除するものではありません。画面に表示されたものを撮影するだけです
> - AI の利用には Google のアカウントと、少額の利用料（1 巻あたり数十円程度）がかかります

---

## 1. 必要なもの

| 必要なもの | 補足 |
|---|---|
| Windows 10 / 11 の PC | 画面の大きいほうが精度が上がります |
| Microsoft Store 版の Kindle アプリ | ストアで「Amazon Kindle」と検索してインストール。旧「Kindle for PC」は使えません |
| 読みたい本 | Kindle で購入済みで、PC にダウンロードできるもの |
| Google アカウント | Gmail のアカウントで構いません |
| クレジットカードまたはデビットカード | AI の利用料の支払いに使います（2 章） |
| このアプリ（zip ファイル） | 配布された `manga-dialogue-windows.zip` |

---

## 2. Gemini API キーを作る（AI を使うための鍵）

このアプリは Google の AI「Gemini」を使います。使うには **API キー**（長いパスワードのような文字列）が必要です。
一度作れば、以後は同じキーを使い続けられます。

### 2-1. キーを作成する

1. ブラウザで **https://aistudio.google.com/apikey** を開き、Google アカウントでログインします
2. 初めての場合は利用規約への同意を求められるので、内容を確認して同意します
3. **「Create API key」**（API キーを作成）ボタンを押します
   - **キー名（Key name）** を聞かれたら、何に使うキーか自分が分かる名前を自由に入力します。
     例: `manga-dialogue`、`漫画セリフ抽出`、`kindle-tool`。あとで変更でき、動作には影響しません
   - 「プロジェクト」を選ぶ画面が出たら、そのまま既定のもの（自動で作られます）で進めてください。
     プロジェクト名の入力を求められた場合も、キー名と同じ考え方で構いません（例: `manga-dialogue`）
4. 作成されたキー（`AIza…` で始まる長い文字列）が表示されます。右側の **コピー**ボタンでコピーし、
   メモ帳などに貼り付けて保管してください

> **API キーは必ず秘密にしてください。**
> キーを知っている人は誰でも、あなたのアカウントとして AI を使えます。第三者に漏れると、
> 勝手に使われて **あなたのカードや前払い残高から利用料が消費される** おそれがあります。
> - 他人に見せたり、メール・チャット・SNS に貼ったり、スクリーンショットに写り込ませたりしないでください
> - このアプリの設定画面以外の場所（Web サイトや他のアプリ）に入力しないでください
> - 漏れたかもしれないと思ったら、すぐに https://aistudio.google.com/apikey でそのキーを **削除** し、
>   新しいキーを作ってアプリの設定を書き換えてください。削除した古いキーは使えなくなります
> - 被害を限定するため、支払いは **前払い（Prepay）** にし、**月額上限**（2-3 節）も設定しておくと安心です

### 2-2. 支払い方法を設定する（有料プランにする）

キーを作った直後は**無料枠**の状態です。無料枠は 1 分あたりの利用回数に厳しい制限があるため、
1 巻まとめて処理すると途中で止まったり、とても時間がかかったりします。
また、無料枠では送った画像や文章が Google のサービス改善に使われることがあります。
**有料プランに切り替えることを強くおすすめします**（切り替えても、使わなければ料金はかかりません）。

1. 同じページ（API キーの一覧）で、自分のプロジェクトの行にある **「Set up billing」**（お支払いを設定）を押します
2. 初めての場合は次の順に入力します
   1. 国（日本）を選び、利用規約に同意
   2. 連絡先（氏名・住所）
   3. 支払い方法（カード番号など）
3. プランを選びます
   - **Prepay（前払い）**: 最初にまとまった金額（最低 5 ドル程度）をチャージし、その分だけ使えます。**使いすぎの心配がないので、こちらをおすすめします**
   - **Postpay（後払い）**: 使った分が毎月請求されます
4. 「有料」への切り替えが完了すると、一覧の表示が変わります

### 2-3. 使いすぎを防ぐ設定（任意）

後払いにした場合や念のため上限を決めたい場合は、AI Studio の **「Spend」**（支出）ページで
**「Monthly spend cap」→「Edit spend cap」** から月ごとの上限金額を設定できます。
上限に達すると AI の利用が止まるだけで、追加の請求は発生しません。

### 費用の目安

- 標準のモデル（Gemini 3.7 Flash）で、漫画 1 巻（約 200 ページ）の書き起こしに **数十円**程度です
- 台帳の整理や再抽出を行うと、その分が追加されます。それでも 1 巻あたり 100 円を超えることはまれです
- 実際の使用量は AI Studio の Spend ページで確認できます

## 3. アプリをインストールする

1. 配布された `manga-dialogue-windows.zip` を、**日本語を含まない場所**に展開（右クリック →「すべて展開」）します。例: `C:\Tools\manga-dialogue\`
   - デスクトップやダウンロードフォルダのままでも動きますが、後で移動すると設定がずれるので、置き場所を決めてから展開してください
2. 展開したフォルダの中の **`manga_dialogue_gui.exe`** をダブルクリックします
3. 初回は「**Windows によって PC が保護されました**」という青い画面が出ることがあります。
   これはアプリに電子署名がないためで、**「詳細情報」→「実行」** を押してください（2 回目以降は出ません）
4. アプリの画面が開けばインストールは完了です。書き起こしたデータは、アプリと同じフォルダの中の `works` フォルダに保存されます

> 展開したフォルダの中には `engine` というフォルダがあります。これは AI との通信やキャプチャを行う本体で、
> アプリが自動的に使います。中のファイルを移動・削除しないでください。

---

## 4. 最初の設定（一度だけ）

1. アプリ右上の **歯車アイコン**（設定）を押します
2. 「エンジン」の項目で **「同梱エンジンを使う」** を押します（起動コマンドの欄に `engine` フォルダのパスが入ります）
3. 「API キー」の **GEMINI_API_KEY** 欄に、2 章でコピーしたキーを貼り付けます
4. **「保存」** を押し、続けて **「接続確認」** を押します。「gemini: API キー 設定済み」と表示されれば完了です
   - 結果の works の行に **「（存在しません）」** と付いていても正常です。works フォルダはまだ何もキャプチャしていないため
     無いだけで、最初のキャプチャを始めたときに自動で作られます
   - 「接続できません」と出る場合は、zip を展開し直していないか、`engine` フォルダが揃っているかを確認してください

> API キーは、この PC のユーザーフォルダにある設定ファイルに **そのままの文字列で** 保存されます。PC を他の人と共用している場合、その人にキーを読まれる可能性があります。共用 PC では使わない、または使い終わったらキーを削除する（12 章）ことをおすすめします。

## 5. Kindle の準備

1. Kindle アプリで対象の本を開きます
2. **見開き（2 ページ）表示**にします。ウィンドウを横に広げると自動で見開きになります。見開きのほうが、前後のページの会話を見て話者を判断できるため精度が上がります
3. **表紙（1 ページ目）** を表示した状態にします
4. Kindle のウィンドウは、できるだけ大きくしてください（画面が大きいほど文字を正確に読み取れます）。最小化はしないでください

---

## 6. 本をキャプチャする（撮影）

1. アプリのトップ画面で **「新しい作品をキャプチャ」** を押します
2. 作品名（好きな名前で構いません。フォルダ名になります）と巻数（1 巻なら 1）を入れます。他の項目はそのままで構いません
3. **「キャプチャ開始」** を押すと、Kindle が前面に出て自動でページ送りと撮影が始まります
   - **撮影中はマウスやキーボードに触れないでください**（別の画面が前に出ると、その画面が撮影されてしまいます）
   - 1 ページ 1.5 秒ほどなので、200 ページなら 5 分程度です
   - 最後のページまで進むと自動で止まります
4. 終わったらアプリに戻り、巻の行（「1巻 キャプチャ ○○枚」）の **「キャプチャを確認」** を押して撮影結果を眺めます
   - 最後に Kindle の「この本を評価」などの画面が混ざっていることがあります。その画像をクリックして選び、右上の **「削除」** で消してください
   - 全体が真っ黒・真っ白なら、Kindle が前面に出ていなかった可能性があります。Kindle を表紙に戻して、巻の行の「…」→「この巻を削除」のあと、もう一度キャプチャしてください

---

## 7. セリフを書き起こす（抽出）

1. トップ画面で巻の行の **「抽出」** を押します
2. 設定はそのままで **「実行」**（モデルは標準の Gemini、抽出が終わると自動で「台帳の外見の検証」も行われます）
3. 右上の **チェックマークのアイコン**（ジョブ）で進み具合を見られます。1 巻で 10〜20 分ほどです
4. 終わると巻の行が「抽出済み」になり、**「開く」** で結果を見られます

> 途中で止まったりエラーが出た場合は、もう一度「抽出」を押してください。終わったページはスキップして続きから再開します。

---

## 8. 結果を確認・修正する

**「開く」** で出る画面が中心です。左に本の画像、右にセリフの表が並びます。

| やりたいこと | 操作 |
|---|---|
| ページを進める / 戻る | キーボードの **←** で次のページ、**→** で前のページ（漫画の読み方向と同じ）。上部の「◀ ▶」でも可 |
| 画像上の番号を一時的に消す | 画像にマウスを乗せると、カーソルの近くの番号だけ消えます。**M** キーで全部の表示 / 非表示 |
| 話者（誰のセリフか）を直す | 表の話者欄をクリックし、名前を入力（途中まで打つと候補が出ます）。Enter で確定 |
| セリフの文字を直す | 本文をクリックして編集し、Enter |
| セリフの順番を直す | 行を選んで、上部の ↑ ↓ ボタン |
| 行を追加 / 削除 | 画像の吹き出しをクリックすると、その位置に行が追加されます。削除は行の右端のゴミ箱、または行を選んで **Ctrl+Backspace** |
| 直したところを AI に上書きさせない | 直した行には自動で「修正済み」の印が付き、再抽出でも上書きされません。ページ全体を確定するなら右上の「確定」 |
| 元に戻す | **Ctrl+Z**（上部の「元に戻す」ボタンでも可） |

### 登場人物の一覧（台帳）
画面右上の **人物アイコン**で開きます。AI が見つけた登場人物の名前・外見が並びます。

- 名前が間違っている、同じ人が 2 つに分かれている → 名前をクリック → 名前を書き換える（別の人物の名前にすると統合されます）
- 名前が分からず「〜（仮）」になっている人物 → 名前が分かったら同様に書き換えます
- **「改名候補のレビュー」** → AI が「この仮名はこの人物ではないか」と提案したものを、根拠を見ながら承認 / 却下できます
- **「台帳を整理」** → 全体のセリフを読み直して仮名の解決や重複の統合を提案させます（1 巻で数円）

> 主要な人物（主人公など）の外見が明らかに別人になっている場合は、「台帳の外見を検証」を押してから巻の行の「再抽出…」で全ページをやり直すと直ります。

---

## 9. 表に書き出す（エクスポート）

1. 巻の行の **「…」→「この巻をエクスポート…」**（または編集画面右上のダウンロードアイコン）
2. 形式は **CSV** のままで、「Excel に対応した形式」にチェックが入っていることを確認して、保存先フォルダを選びます
3. `作品名_01.csv` のようなファイルができます。Excel でそのまま開けます

列の意味: `volume`（巻）、`page`（撮影したページ番号）、`panel`（コマ番号）、`speaker`（話者）、`text`（セリフ）、
`confidence`（AI の確信度）、`basis`（判定の根拠。tail = 吹き出しの尻尾で判定）、`manual`（手で直した行）

---

## 10. 2 巻目以降

1. Kindle で次の巻を開き、見開きで表紙を表示します
2. トップ画面で作品を選び、巻一覧の下の **「巻を追加してキャプチャ」** を押します（巻番号は自動で次の番号になります）
3. あとは 6〜9 章と同じです。登場人物の台帳は前の巻から引き継がれるので、話者の判定はより正確になります

## 11. 困ったときは

| 症状 | 対処 |
|---|---|
| 接続確認で「API キー 未設定」 | 設定画面のキーを貼り直して「保存」→「接続確認」 |
| 抽出が「API エラー」「credit」「billing」といったメッセージで止まる | 2-2 の支払い設定ができていない、または前払い残高が切れています。AI Studio で確認してください |
| 抽出が途中でとても遅くなる、同じところで止まる | 無料枠の回数制限の可能性が高いです。有料プランに切り替えてください |
| 「Kindle が起動していません」 | Kindle アプリで本を開いた状態にしてから実行してください。最小化しないでください |
| 撮影した画像が本と違う画面になっている | 撮影中に別のウィンドウが前に出ました。Kindle を表紙に戻し、巻を削除してからもう一度撮影してください |
| Windows のセキュリティ警告で起動できない | 3 章の「詳細情報」→「実行」を押してください |
| 話者が別の人になっているページが多い | 台帳の外見が入れ替わっている可能性があります。8 章末尾の「台帳の外見を検証」→「再抽出…」を試してください |

---

## 12. データの場所と削除

- すべてのデータ（撮影画像・書き起こし・台帳）は、アプリと同じフォルダの `works` に入っています。作品や巻ごとの削除はアプリの「…」メニューから行えます
- アプリを使わなくなったら、展開したフォルダを丸ごと削除すれば完全に消えます。API キーの設定ファイルは `C:\Users\<ユーザー名>\.manga_dialogue_gui.json` です。不要になれば削除してください
- AI Studio 側のキーも、使わなくなったら削除しておくと安全です
